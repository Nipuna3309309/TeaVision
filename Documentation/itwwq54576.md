# Models in Component IT22154576 (MIT22154576)

Based on the documentation for the subsystem architecture, the following models are utilized across the three primary features:

## 1. Object Detection Model
- **Algorithm/Architecture:** YOLOv8 (specifically using weights like `teanet_rf_v4`).
- **Use Case:** "Tea Leaf Detection System" — Fast-pass visual inspection for tea leaf quality.
- **Functionality:** Detects and counts `Fresh_Bud`, `Coarse_pluck`, and `Damage_Spot` classes from high-resolution imagery. It uses **SAHI (Slicing Aided Hyper Inference)** to slice large images into smaller grids before predicting with YOLOv8, ensuring tiny tea buds don't get overlooked during scaling.

## 2. Machine Learning Classification Models
- **Algorithms:** Classical machine learning models, primarily featuring **Random Forest**, **MLP Neural Network**, and **SVM (Support Vector Machine)**.
- **Use Case:** "Grade My Tea" — Mathematical classification to judge whether a leaf is `High Quality` or `Medium Quality`.
- **Functionality:** Instead of purely acting on raw image pixels, the pipeline extracts **25 hand-crafted features** using OpenCV (11 color, 3 texture, 7 shape, and 4 quality features). These 25 features are fed into the respective ML model to return a binary classification and its confidence scores.

## 3. Vector Embeddings Search Model
- **Algorithm:** Text Vector Embedding Model (specifically for search operations).
- **Use Case:** "Ceylon Tea Knowledge Base" — Semantic text search engine.
- **Functionality:** In a core Retrieval-Augmented Generation (RAG) system, user questions are converted into vector embeddings and compared against pre-embedded document chunks representing thousands of paragraphs of Sri Lankan Tea literature. The model retrieves the most semantically relevant results (K=10 similarity limit).

## Complete Feature Implementation Summary (Start-to-Finish)

Below is a detailed breakdown of all components developed for **MIT22154576**, tracking the exact data flow from the React frontend deep into the Python backend engine:

### 1. Tea Leaf Detection System (YOLOv8 + SAHI)
- **Frontend (`DetectionPage.jsx`)**: Built a React interface featuring image upload capabilities via drag-and-drop, device camera, and a local network mobile sync (`/mobile/upload`). Integrated a settings panel allowing users to dynamically select models via the `/models` endpoint, adjust confidence thresholds, and toggle SAHI on/off. Results render side-by-side original vs. annotated images, compute class distributions (e.g., Fresh Bud 1 vs Damage Spot), and extract detailed light/measurement analytics parsed directly from `Teavision` Exif meta-data.
- **Backend (`detection.py`, `main.py`)**: Engineered the `/detect` API. Built an advanced detection pipeline running custom-trained YOLO weights. Integrated **SAHI (Slicing Aided Hyper Inference)**, which programmatically slices high-resolution images into grids (e.g., 512x512) before passing them to YOLO. This ensures microscopic features like tea buds aren't destroyed when the image down-scales. Implemented robust Non-Maximum Suppression (NMS) to prune overlapping bounding boxes and mapped counts into an automated "Quality Grade" classifier (A-D).

### 2. Grade My Tea Classification (Machine Learning + OpenCV Pipeline)
- **Frontend (`GradingPage.jsx`)**: Designed a dashboard specifically for leaf quality classification. Created a dynamic "Model Comparison" table extracting performance metrics (Test Accuracy & F1 Scores) for multiple ML models from the backend. Incorporated an "Environment Analysis" module where users can gauge light uniformity and manually override camera distance. Renders the binary verdict (`High Quality` vs `Medium Quality`), probability distribution bars, and a breakdown of the 25 specific features driving the AI's decision.
- **Backend (`detection.py`, `main.py`)**: Built the `/classify` endpoint incorporating a rigorous **OpenCV Feature Extraction** pipeline (`extract_features_from_image`). Instead of relying on a black-box CNN, the system explicitly calculates **25 hand-crafted metrics**:
  - **11 Color Features** (RGB, HSV, LAB statistics)
  - **3 Texture Features** (Gray Level Co-occurrence Matrix, Local Binary Patterns)
  - **7 Shape Features** (Contour Areas, Solidity, Aspect Ratios)
  - **4 Quality Metrics** (Brightness, Contrast)
  These metrics are passed through a `StandardScaler` and into classical ML models loaded from binaries (`.pkl` files like MLP, Random Forest, AdaBoost) to generate the final classification.

### 3. Ceylon Tea Knowledge Base (RAG System)
- **Frontend (`KnowledgePage.jsx`)**: Developed a comprehensive 3-tab portal encompassing "Search", "Browse", and "Categories". Implemented interactive visual filters utilizing category-specific emojis and colors (e.g., Cultivar 🌱, Processing ⚙️). Users can execute queries to fetch relevant text, and clicking a result card opens a modal overlaying the exact contextual document chunk. Integrated live statistics pulling doc, chunk, and category counts directly from the backend.
- **Backend (`main.py`)**: Built the entire Retrieval-Augmented Generation infrastructure. The `/search`, `/documents`, and `/stats` endpoints parse `tea_corpus.json` and vectorized chunk data. The semantic search architecture matches queries against document chunks using pre-computed vector embeddings (`all-MiniLM-L6-v2`) and a BM25 index. Engineered a two-stage retrieval sequence: an initial semantic vector search, followed by an internal fallback to a robust rule-based expert dataset (`CATEGORIZED_TREATMENTS`) to gracefully handle sparse queries.
