## 1. Tea Leaf Detection System (1 Minute)
*(While showing `DetectionPage.jsx`)*
"Welcome to the Tea Leaf Detection System. The goal here is to perform a fast-pass visual inspection. Users can upload high-resolution images via drag-and-drop, take a live photo, or sync directly from their smartphone using our TeaVision mobile bridge. 

Behind the scenes, we are running a custom-trained YOLOv8 object detection model. What makes this system unique is our integration of **SAHI**—Slicing Aided Hyper Inference. Instead of shrinking a large 4K image and losing microscopic details, the backend algorithmically slices the image into smaller grids, runs YOLO on each slice independently, and logically merges the bounding boxes. 

As you can see on the screen, the system successfully counts the total leaves and precisely draws boxes around individual Fresh Buds versus Coarse Plucks or Damaged Spots. Based on the ratio of good-to-bad detections, it automatically assigns a Quality Grade from A to D, allowing factories to immediately flag poor-quality batches at the intake stage."

## 2. Grade My Tea Classification (1 Minute)
*(While showing `GradingPage.jsx`)*
"Moving on to 'Grade My Tea', this dashboard acts as our mathematical quality classifier. While the previous screen simply counted leaves, this subsystem analyzes the physical metrics of the leaf to assign a 'High' or 'Medium' quality status.

Notice the 'Environment Analysis' panel on the side. Before we classify, the system parses EXIF data and pixel brightness to score the lighting conditions, ensuring the image is actually suitable for analysis. 

When we hit Classify, we don't just use a standard black-box Convolutional Network. Instead, my backend runs OpenCV pipelines to meticulously extract **25 hand-crafted features** from the image. This includes 11 specific color statistics from RGB/HSV/LAB spaces, texture metrics like Local Binary Patterns, and shape metrics like Solidity. These 25 floating-point numbers are then fed into classical Machine Learning models. The user can even dynamically compare the Test Accuracy and F1 scores of different models, such as Random Forest or MLP Neural Networks, directly from this UI to pick the most accurate classifier."

## 3. Ceylon Tea Knowledge Base (1 Minute)
*(While showing `KnowledgePage.jsx`)*
"Finally, we have the Ceylon Tea Knowledge Base. This is a semantic search engine built using a Retrieval-Augmented Generation (RAG) architecture. 

As you can see from the live statistics, we have pre-embedded thousands of paragraphs of Sri Lankan agricultural literature. The user interface allows you to browse visually by category, like Cultivars or Processing methods, or use the smart search bar. 

When a user types a human-readable question like *'What are the health benefits of black tea?'*, the backend converts that query into a vector embedding. It mathematically compares that vector against our document embeddings using similarity search. Within milliseconds, it returns the top 10 most relevant text chunks. If I click on a result, the modal opens showing the exact, verified document chunk the AI found, allowing estate managers and workers to instantly retrieve standard operating procedures and treatment instructions without manually reading through heavy manuals."
